# Currency Converter

> ⚠️ **Тестовый кейс.** Учебное приложение для практики работы с HTTP и формами, а не финансовый сервис.

Приложение показывает текущие курсы валют и конвертирует суммы между валютами.

## Стек

- Angular 18
- Angular Material / CDK
- TypeScript 5.5
- RxJS 7.8

## Запуск

```bash
npm install
npm start        # http://localhost:4200
```

## Скрипты

| Команда         | Назначение                          |
| --------------- | ----------------------------------- |
| `npm start`     | dev-сервер                          |
| `npm run build` | сборка                              |
| `npm run watch` | сборка в watch-режиме (development) |

## Функциональность

- Просмотр текущих курсов
- Конвертация между валютами

## Цель кейса

- Работа с внешним API через `HttpClient` и RxJS.
- Реактивные формы и валидация ввода.
